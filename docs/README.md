# Documentation

Use this directory as the entry point for design-system decisions and engineering handoff material.

## Start here

- [Engineering Handoff Index](handoffs/ENGINEERING_HANDOFF_INDEX.md) — implementation routes, source priority, and acceptance guidance
- [Design System Specification](specifications/DESIGN_SYSTEM_SPECIFICATION.md) — canonical component behavior and visual specification
- [Component Inventory](specifications/DESIGN_SYSTEM_COMPONENT_INVENTORY.md) — component coverage and readiness
- [Token Architecture](tokens/CVP_TOKEN_ARCHITECTURE.md) — token tiers, naming, and dependency rules
- [Token Governance](tokens/TOKEN_GOVERNANCE.md) — ownership, review, deprecation, and compliance
- [Implementation Status](project/IMPLEMENTATION_STATUS.md) — current progress and outstanding work

## Directory guide

| Directory | Contents |
| --- | --- |
| `specifications/` | Canonical system specification, inventory, and historical design reference |
| `tokens/` | Architecture, contracts, governance, reconciliation, and decision framework |
| `handoffs/components/` | Component-specific standards and developer handoffs |
| `handoffs/checkpoints/` | Family-level completion checkpoints and readiness reviews |
| `handoffs/tickets/` | Implementation-ready engineering tickets |
| `assessments/foundations/` | Foundation assessments and visual preview assets |
| `assessments/accessibility/` | Accessibility and contrast audits |
| `figma/` | Figma design-system guidance |
| `project/` | Implementation status and project-level tracking |
| `legal/` | Attribution and legal notes |

Runtime code and token CSS remain under `src/`; this directory contains guidance and specifications only.
